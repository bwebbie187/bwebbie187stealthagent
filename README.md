# bwebbie187stealthagent

A simple onchain micro‑agent built for the Base network.  
This agent listens for signals, performs small automated actions,  
and demonstrates how lightweight autonomous logic can run cheaply  
on Base L2.

## What This Agent Does
- Stores a message or “signal” onchain  
- Lets users update the signal  
- Emits events so other apps or agents can react  
- Uses Base’s low‑cost transactions to stay cheap and accessible  

## Why This Matters
Base is building an ecosystem of onchain agents that automate tasks,  
react to events, and create new forms of coordination.  
This project is a minimal example of how an agent can live on Base  
and interact with users or other contracts.

## Tech Stack
- Solidity  
- Base L2  
- Hardhat (or Foundry)  
- Coinbase Wallet / MetaMask
